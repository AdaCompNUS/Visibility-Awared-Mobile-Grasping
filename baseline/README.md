# Learning Baselines

Two learning baselines for the visibility-aware mobile grasping benchmark:

| Folder | Baseline | Method source |
| ------ | -------- | ------------- |
| `RL/`  | Image-input reinforcement learning — MS-HAB's SAC Pick policy, trained with the unmodified upstream pipeline | [ManiSkill-HAB](https://github.com/arth-shukla/mshab) (ICLR 2025) |
| `VLA/` | Vision-language-action imitation — SG-VLA-style policy trained on data generated by the MS-HAB pipeline | [SG-VLA](https://arxiv.org/abs/2603.22760) (no code released; reimplementation) |

Both run in the dedicated `rl` pixi environment defined in the repository root
`pixi.toml` (`pixi run -e rl <cmd>`). That environment pins the `mshab` branch
of ManiSkill3 — the exact simulator snapshot both papers trained on — and is
fully isolated from the default environment, which keeps the released
`mani_skill 3.0.1` used by the main benchmark.

Training happens in MS-HAB's own environments, untouched. Only *evaluation*
happens on our benchmark (400 grasp tasks, 20 ReplicaCAD scenes, static +
dynamic-obstacle conditions), so the comparison is: published method, published
training recipe, tested on our task.
